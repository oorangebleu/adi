# Adi's Block Drop

A simple browser-based Tetris-style game for Adi, designed to run as a static website.

## Play locally

Run a local web server from the project folder:

```bash
npm start
```

Then open http://localhost:8000

## Publish to GitHub Pages

1. Push this repository to GitHub.
2. Open the repository on GitHub.
3. Go to Settings → Pages.
4. Choose "GitHub Actions" as the source.
5. The workflow in .github/workflows/deploy-pages.yml will publish the site automatically.
